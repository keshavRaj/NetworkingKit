# NetworkingKit

A modern, lightweight, and reusable networking library built with Swift Concurrency.

This project is being developed as a learning journey to understand how production-quality networking libraries are designed and implemented using native Apple frameworks.

## Goals

- Learn URLSession deeply
- Build a reusable networking layer
- Use async/await and Swift Concurrency
- Follow Clean Architecture principles
- Support unit testing
- Document design decisions
- Integrate with the Movie Discovery app
